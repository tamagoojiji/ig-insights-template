# 社内サポート用FAQ（クリエイター用）

利用者からの典型的な問い合わせに対する回答テンプレート。

## トラブル系

### Q: 接続テストで「Instagram API Error: ...」が出る
- アクセストークンの権限不足が大半。`instagram_basic` `instagram_manage_insights` `pages_read_engagement` `pages_show_list` の4つが付いているか確認
- 短期トークンが切れている可能性 → Graph API Explorer で再取得して短期トークンを再貼り付け

### Q: 「長期トークンへの変換に失敗しました」
- FB_APP_ID / FB_APP_SECRET が間違っている or 未設定
- アプリの「ベーシック」設定で「アプリの状態」が「ライブ」でない（開発モードでもOKだが、設定値が反映されていない場合あり）

### Q: ストーリーズが取れない
- API仕様で **24時間以内のみ** 取得可。過去分は「📦 Meta公式zipアップロード」を使用
- IGアカウントが「クリエイター」ではなく「個人」の場合は不可（ビジネス/クリエイターに切替必須）

### Q: トリガーが動かない
- Apps Script の「トリガー」画面で `autoFetch` が登録されているか確認
- スプシのオーナーアカウントとトリガー作成アカウントが同じか確認

### Q: Drive画像保存フォルダが「見つかりません」
- フォルダIDを直接編集した可能性 → 「📁 Drive画像保存フォルダを準備」を再実行で自動再作成

### Q: トークンが期限切れになった（60日超過）
- 「🔄 トークン手動更新」を実行 → 失敗する場合は短期トークンから取り直し
- 30日以上スプシを開かない期間があると失効リスクが高まるため、月1回以上は開く運用を推奨

### Q: Meta zipアップロードで「ファイルサイズ超過」
- Apps Script の制約上、50MB以内推奨
- Meta側で「期間」を分割エクスポート（例: 半年単位）→ 複数回アップロードで対応

### Q: OCRが動かない
- GEMINI_API_KEY が未設定 → AI Studio (https://aistudio.google.com) で発行・設定シートに貼付
- API無料枠を超過した可能性 → Google Cloud Console で課金有効化

## 仕様確認系

### Q: 取得指標の意味
- views: 閲覧数（リールは再生数）
- reach: ユニーク到達数
- saved: 保存数
- shares: シェア数
- total_interactions: いいね+コメント+保存+シェアの合計
- ig_reels_avg_watch_time: リールの平均視聴時間（ミリ秒）
- navigation（ストーリーズ）: タップ前進・タップ後退・退出の合計
- profile_visits（ストーリーズ）: ストーリーズ経由のプロフィール訪問数
- follows（ストーリーズ）: ストーリーズ経由の新規フォロー数

### Q: 自動取得の頻度を変えたい
- `gas/triggers.js:25` の `everyMinutes(30)` を変更可能（最短10分推奨）
- 短くするとMeta API rate limit に達しやすくなるため非推奨

### Q: 古い投稿のキャプションが切れている
- 旧版で保存された行は「📝 既存キャプションを全文化」メニューで更新可能

## 法的・規約系

### Q: スクレイピング使ってないか
- 使っていません。Meta公式 Instagram Graph API のみ使用
- 詳細は `internal/legal-notes.md` 参照

### Q: 取得したデータを再販してもいい？
- 自分のアカウントの統計データを **自分のサービス内で使う** のは問題なし
- データを **第三者に再販** する場合は Meta規約・個人情報保護法の確認が必要（クライアントワーク等）

## 価格・購入系

### Q: 別IGアカウントで使い回せる？
- 1スプシ = 1IGアカウント設計。複数アカウント分のスプシをコピーすれば対応可
- 同一購入者が複数アカウント運用する場合は問題なし
