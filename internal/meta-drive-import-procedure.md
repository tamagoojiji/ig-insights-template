# Meta公式データ取り込み（Driveフォルダ経由・大容量対応）手順

1GB級のMeta公式エクスポートを Google Drive 経由でスプシに取り込む手順。
Apps Script の `Utilities.unzip` には 50MB の Blob制限があるため、**ローカルでzipを展開し、展開後フォルダをDriveにアップロードする方式**を採用する。6分実行制限はカーソル方式で自動再開する。

## 前提

- スプシGASに最新コード（`meta-drive-import.js` / `meta-drive-dialog.html`）が反映済み
- 「⚙️ 設定」で `DRIVE_FOLDER_ID`（画像保存先フォルダ）が設定済み

## 流れ

```
[Meta] → [ローカル] → [Google Drive] → [スプシGAS] → [スプシ + 画像Drive]
 zip      展開         フォルダUL       Drive走査
                                       JSON→履歴
                                       画像→Drive
```

---

## Step 1: Metaから「JSON形式」でデータをダウンロード

1. Instagramアプリ or PCで [アカウントセンター → 情報をダウンロード](https://accountscenter.facebook.com/info_and_permissions/dyi)
2. **形式: JSON**、**期間: すべての履歴** を選択
3. 申請後、数時間〜24時間で完了通知メール
4. メール内のリンクからzipをダウンロード（PCのダウンロードフォルダ等に保存）

> 📷 スクショ枠: ダウンロードページ／メール／zipファイル

---

## Step 2: ローカルでzipを展開

Macの場合、zipをダブルクリックで展開フォルダができる（例: `instagram-xxx-2026-05-16-xxx/`）。

展開後の構造（典型）:
```
instagram-xxx-2026-05-16-xxx/
├── your_instagram_activity/
│   ├── content/
│   │   ├── posts_1.json
│   │   ├── posts_2.json   ← 投稿が多いと分割される
│   │   ├── reels.json
│   │   └── stories.json
│   └── media/
│       ├── posts/
│       │   ├── 202501/xxx.jpg
│       │   └── ...
│       ├── reels/
│       └── stories/
└── ...
```

> 📷 スクショ枠: Finderで展開後のフォルダを開いたところ

---

## Step 3: 展開後フォルダ全体を Google Drive にアップロード

1. ブラウザで [Google Drive](https://drive.google.com) を開く
2. **マイドライブ** に移動（または専用フォルダを作って整理してもOK）
3. **展開後フォルダ全体**（例: `instagram-xxx-2026-05-16-xxx`）を Drive のウィンドウへ **ドラッグ&ドロップ**
4. 右下に進捗バーが出る。1GBクラスは **20分〜1時間** かかることもある（ネット速度依存）
5. すべて緑チェックになるまで待つ

> 📷 スクショ枠: Driveへドラッグしているところ／進捗バー／完了表示

⚠️ アップロード中はPCをスリープさせない。

---

## Step 4: フォルダURLをコピー

1. Driveでアップロードしたフォルダ（例: `instagram-xxx-2026-05-16-xxx`）を右クリック
2. **共有 → リンクをコピー**（権限は「制限付き」のままで自分専用にしておく）
3. クリップボードに `https://drive.google.com/drive/folders/<長いID>?usp=sharing` のようなURLがコピーされる

または: フォルダをダブルクリックで開き、アドレスバーのURLをコピーしてもOK。

> 📷 スクショ枠: 右クリックメニュー／コピーしたURL

---

## Step 5: スプシで取り込み実行

1. スプシを開く → メニュー **「📊 Instagram Insights → 📁 Meta公式データ取り込み（Driveフォルダ経由・大容量対応）」**
2. ダイアログが開く
3. 「DriveフォルダURL（複数なら1行に1つずつ）」入力欄に **Step 4 でコピーしたURLを全部・1行に1つずつ貼り付け**
   - Metaが複数zipに分割した場合: 展開後フォルダ全てのURLを貼る
   - 1つだけでもOK
4. **「☑ 中断時に自動的に続行する（完了まで繰り返し）」 のチェックが入っていることを確認**（デフォルトON）
   - これがOFFだと5分ごとに手動で「続行」を押す必要がある
   - **大量データの場合は必ずON** にしておく
5. **「取り込み開始」** ボタンを押す
6. 5分制限で中断 → **3秒後に自動で「続行」が走る** → 5分処理 → 自動再続行 → ... を完了まで繰り返し
7. 全完了で「✅ Meta Drive取り込み完了」サマリーが表示される
8. 途中で停止したい場合は **チェックボックスをOFF** にする（次の中断時に停止）

> 📷 スクショ枠: 07-progress-with-auto-resume.png（チェックON＋進捗バー動作中）

### ⚠️ ダイアログを閉じない

- 自動再開はダイアログ上のJavaScriptで動いているため、**ダイアログを×で閉じると停止します**
- ブラウザのタブを閉じても停止します
- スプシのタブはそのまま開いたまま作業してください

### 完了サマリー例
```
✅ Meta Drive取り込み完了

📸 フィード追加: 1234件
🎬 リール追加: 567件
📖 ストーリーズ追加: 8901件
🖼 画像保存: 10000件
⏭ 既存スキップ: 0件
```

### 中断サマリー例
```

...

```

---

## Step 6: 自動再開が動かなくなったときの手動再開

通常は Step 5 の自動再開で完了まで進むが、何らかの理由で止まったとき:

1. ダイアログがそのまま残っていれば **「続行（中断分の再開）」** ボタンを手動で押す
2. ダイアログが消えてしまった場合: スプシをリロード → メニュー再選択 → **「続行」**（URLは再貼付不要、カーソルから再開）
3. 完了するまで何度でも続行可
4. 完了すれば「✅ Meta Drive取り込み完了」と表示

---

## Step 7: 取り込み結果の確認

1. スプシのシート「📸 フィード履歴 / 🎬 リール履歴 / 📖 ストーリーズ履歴」を開く
2. `source` 列が `meta_drive` になっている行が新規追加分
3. 「画像URL」列にDriveのサムネURLが入っていれば画像保存もOK
4. **「📖 ストーリーズ」（メインシート）** にもストーリーズが反映される
   - 「画像内テキスト」列にはMetaキャプション（OCR列に流用）が入る
   - 後で OCR を別途かけたければ「🔍 ストーリーズOCR一括」

> 📷 スクショ枠: 履歴シートに行が増えているところ／画像URLクリックで画像表示

## トラブルシュート

| 症状 | 対処 |
|------|------|
| 「DriveフォルダURLからフォルダIDを抽出できませんでした」 | URL形式を再確認。生のフォルダID（20文字以上の英数字）でも可 |
| 「Metaの content JSON が見つかりません」 | 展開後フォルダの **トップ階層** をアップロードしているか確認。`your_instagram_activity` 単体だけだと深さが足りないことがある |
| 「画像保存失敗」がLogger.logに大量 | `DRIVE_FOLDER_ID` 未設定 or 画像blobが取得できていない（GAS Blob 50MB制限を超える動画ファイルなど） |
| 同じURIで2回取り込まれた | meta_<timestamp>_<hash> ID で重複検出するため発生しないはず。発生したら issue 化 |
| カーソルがおかしくなった | ダイアログの「カーソルリセット」を押す。書き込み済みデータは残る |

---

## 別ユーザーへの展開手順（簡易）

1. たまごさんが**そのユーザーのスプシGAS**に最新コードがpush済か確認
2. Driveフォルダのアップロード作業はそのユーザー本人 or たまごさんが代行
3. スプシメニューから上記Step 5以降を実施

⚠️ Driveへのアップロードはアカウントを共有しないため、**そのユーザー自身のGoogleアカウント** で行う必要がある。あるいはたまごさんが共有Driveを介して受け取る運用にする。
