# マスタースプレッドシート 列定義仕様書

利用者が実際に触るシート構成と、システムが自動更新するシート構成を定義する。

## シート一覧

| 種別 | シート名 | 役割 |
|---|---|---|
| 利用者 | `⚙️ 設定` | API キー・ユーザーID・トークン等を貼り付ける入力UI |
| 利用者 | `📸 フィード` | フィード投稿の最新インサイト（1投稿= 1行） |
| 利用者 | `🎬 リール` | リール投稿の最新インサイト（1投稿= 1行） |
| 利用者 | `📖 ストーリーズ` | ストーリーズ投稿の最新インサイト（1投稿= 1行） |
| 利用者 | `📊 ダッシュボード` | 集計結果の可視化（伸びた投稿・初速・曜日×時間ヒートマップ） |
| 集計 | `🏆 伸びた投稿` / `🏆 フィード伸びた投稿` / `🏆 リール伸びた投稿` | 過去30日平均の1.x倍以上を抽出 |
| 集計 | `⚡ 初速良好` / `⚡ フィード初速良好` / `⚡ リール初速良好` | 投稿1時間時点の伸び |
| システム | `📸 フィード履歴` / `🎬 リール履歴` / `📖 ストーリーズ履歴` | 取得時刻ごとの履歴・`source` 列で `api` / `meta_zip` 区別 |

## 列定義（ヘッダー名解決）

各シートの列は **ヘッダー名で解決** する設計（threads-scheduler-template と同流儀）。列順序の変更や列追加に対しても破綻しない。`gas/sheets.js:findColumn_()` がヘッダー文字列で列番号を引く。

### `📸 フィード`
| 列名 | 型 | 自動更新 | 備考 |
|---|---|:---:|---|
| 投稿日時 | 日付 | ✅ | API timestamp |
| サムネ | IMAGE 数式 | ✅ | =IMAGE("https://drive.google.com/thumbnail?id=...") |
| タイプ | 文字列 | ✅ | IMAGE / CAROUSEL_ALBUM |
| キャプション | 文字列 | ✅ | API caption（全文・改行保持） |
| いいね | 数値 | ✅ | like_count |
| コメント | 数値 | ✅ | comments_count |
| 保存 | 数値 | ✅ | saved |
| リーチ | 数値 | ✅ | reach |
| 視聴 | 数値 | ✅ | views |
| 総相互作用 | 数値 | ✅ | total_interactions |
| エンゲージ率 | 数式 | ✅ | =IFERROR(... / リーチ) |
| メディアID | 文字列 | ✅ | API media id |

### `🎬 リール`
フィードと同様の列構成 + `平均視聴時間（秒）` 列（`ig_reels_avg_watch_time` を秒換算）。

### `⚙️ 設定`
- 縦並び・B列ペースト方式
- threads-scheduler-template `gas/setup-sheet.js:10-70` 流儀
- 入力欄（B列の偶数行）: IG_ACCESS_TOKEN / IG_USER_ID / FB_APP_ID / FB_APP_SECRET / DRIVE_FOLDER_ID / GEMINI_API_KEY / WEBHOOK_URL
- メニュー「💾 設定シートからPropertiesに保存」で B列値を Script Properties に転記

## 履歴シートの蓄積戦略

- 取得のたびに **新規行を append**（既存行は更新しない）
- メディアID + 取得時刻 をキーに時系列分析が可能
- ダッシュボードはこの履歴シートから「伸び」「初速」を計算

## 保護設定

- `📸 フィード` / `🎬 リール` / `📖 ストーリーズ` は誤操作防止のためデフォルトで保護なし（利用者が見やすいように）
- システム列（メディアID等）は背景色を薄グレーにして「触らない列」と視覚的に区別
- 履歴シートはデフォルトで非表示（メニューから可視化可能）
