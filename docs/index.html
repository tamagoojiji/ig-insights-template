法的方針（BYO型・スクレイピング不使用）

本テンプレートは Meta公式の Instagram Graph API のみ を使用します。HTMLスクレイピングは行いません。

  • BYO型（Bring Your Own credentials）: Meta App / アクセストークン / Googleアカウント / Gemini APIキー / Discord Webhook はすべて利用者ご自身が用意・管理。配布元のサーバーは介在しません
  • 取得対象は自分のビジネス/クリエイターアカウントのみ: 第三者の非公開アカウントデータは取得しません
  • 過去データの取り込み: API経由 + Meta公式「アカウントセンター→情報をダウンロード」の正規エクスポートzipのみ使用

詳細は できる/条件付き/できない一覧 をご確認ください。

重要な注意事項

  • Instagramビジネス/クリエイターアカウント必須: 個人アカウントでは Graph API のインサイトを取得できません。Facebookページとの連携も必要です
  • ストーリーズはAPI上24時間以内のみ取得可: 過去のストーリーズは Meta公式zipアップロード機能で復元（24時間以上前のデータは数値が一部欠ける場合あり）
  • 取得タイミング: 30分ごとの自動取得トリガー（GAS無料枠の制約上、これより短くは原則不可）
  • 長期トークン60日問題: 60日ごとに利用者の操作（または週次自動更新の成功）が必要。30日以上スプシを開かない場合はトークン失効リスクがあります
  • Meta Developer登録: 利用者様ご自身のMetaアカウントで開発者アカウント・アプリを作成していただきます（Zoom同伴）
  • API仕様変更追随: Meta側のAPI変更時は本テンプレも追従更新を行いますが、保証はベストエフォートです
