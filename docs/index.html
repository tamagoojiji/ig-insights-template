特徴

📊

成績データを自動で記録

見られた数・届いた人数・保存数・シェア数・視聴時間など、インスタが公式に出している数字を、全部自動でスプレッドシートに記録します。

🏠

データは全部あなたのもの

スプレッドシートも画像も、すべてあなた自身のGoogleアカウントの中に保存されます。パスワードやデータを配布元に預ける必要は一切ありません。

📚

過去の投稿もさかのぼって保存

これまでのフィード・リールを全部さかのぼって取り込めます。インスタ公式の「データをダウンロード」機能を使えば、過去のストーリーズも復元できます。

💴

毎月の費用は基本0円

無料で使える仕組みだけで動くので、月額費用は基本かかりません。画像から数字を読み取るオプション機能を使う場合だけ、月に数十円程度かかります。

📊

伸びた投稿がひと目でわかる

伸びた投稿のランキング・投稿直後の反応チェック・反応が良い曜日と時間帯の色分け表を自動で作成。次の投稿の作戦づくりに役立ちます。

🔔

トラブル時はお知らせが届く

データが取れなくなったときや接続が切れそうなときは、チャットアプリ（Discord）に自動でお知らせが届きます。
