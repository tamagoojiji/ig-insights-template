特徴

📊

成績データを自動で記録

閲覧数・リーチ・保存数・シェア数・視聴時間など、インスタが公式に出している数字を、全部自動でスプレッドシートに記録します。

🏠

データは全部あなたのもの

スプレッドシートも画像も、すべてあなた自身のGoogleアカウントの中に保存されます。パスワードやデータを配布元に預ける必要は一切ありません。

📚

過去の投稿取得は購入者特典で

自動で保存されるのは、設定が終わったあとの新しい投稿です。それより前の過去の投稿の取り込みは、購入者特典として別途ご案内します。

💴

毎月の費用は基本0円

無料で使える仕組みだけで動くので、月額費用は基本かかりません。画像から数字を読み取るオプション機能も、無料枠の範囲で基本無料で使えます。

📊

伸びた投稿がひと目でわかる

伸びた投稿のランキング・投稿直後の反応チェック・反応が良い曜日と時間帯の色分け表を自動で作成。次の投稿の作戦づくりに役立ちます。

🔔

トラブル時はお知らせが届く

データが取れなくなったときや接続が切れそうなときは、チャットアプリ（Discord）に自動でお知らせが届きます。

安心してお使いいただくために（規約を守った仕組みです）

このテンプレートは、Meta社（インスタの運営会社）が公式に用意している窓口だけを使ってデータを取得します。規約違反になるような裏ワザ的な方法は一切使いません。

  • 全部あなたのアカウントで管理: データの保存先も、インスタとの接続設定も、すべてあなた自身のアカウントの中で完結します。配布元がパスワードやデータを預かることはありません

  • 過去データの取り込み: 公式の窓口経由と、インスタ公式の「情報をダウンロード」機能で出てくる正規データだけを使います

ご購入前に知っておいてほしいこと

  • インスタの「プロアカウント」への切り替えが必要です: ビジネスまたはクリエイターアカウント（無料・アプリから数タップで切り替え可能）でないと数字を取得できません。Facebookページとのひも付けも必要です（手順書で案内します）

  • インスタ側の仕様変更について: 変更があったときはテンプレートも更新しますが、即日対応をお約束するものではありません
