本テンプレートで何が実現できて、何ができないのかを正確に把握してから導入してください。Instagram Graph API（Meta公式）で取得できる範囲に基づいています。

🟢 できる

項目説明
フィード自動収集views / reach / saved / shares / total_interactions / like_count / comments_count を30分ごとに自動取得・スプシ追記
リール自動収集上記 + ig_reels_avg_watch_time（平均視聴時間）
ストーリーズ自動収集（24h以内）views / reach / replies / shares / total_interactions / navigation / profile_visits / follows を24時間以内に自動保存
画像永続化サムネイルを自分のGoogleドライブに自動保存（feed/reels/stories サブフォルダ自動作成）
過去全件取り込み（API）フィード・リールを過去すべて遡って取得可能（5分制限到達時は自動カーソル保存・再開）
過去ストーリーズの復元（zip経由）Meta公式「アカウントセンター → 情報をダウンロード」zipのアップロードで、過去のストーリーズも履歴シートに追加
ダッシュボード自動生成伸びた投稿ランキング・初速良好判定・曜日×時間帯ヒートマップを自動集計
ストーリーズOCR（任意）Gemini Vision APIキーを設定すると、ストーリーズ画像内のテキストを自動抽出
Discord通知トークン期限切れ・取得エラー・取り込み完了を利用者の指定Discordチャンネルに通知
トークン自動更新60日長期トークンを週次トリガーで自動更新（30日以上スプシを開かない期間が無ければ失効しない）

🟡 条件付きでできる

項目条件・制約
過去のストーリーズ数値の取得Meta公式zipにはキャプション・画像・タイムスタンプは含まれるが、過去のリーチ・閲覧数・反応数の数値は含まれない場合がある。zipに無い数値は空欄として保存。最新24時間のものはAPI経由で取得可
CAROUSEL（複数枚投稿）1投稿= 1行で記録。サムネイル画像のみ保存（子要素の個別画像は保存対象外）。インサイトは投稿全体の合計値
Meta zipアップロードApps Script制約上、zipは 50MB以内を推奨。超える場合はMeta側で期間を分割エクスポート
過去数年分の遡取得Graph API のレート制限（200call/h/user）の関係で、数千件の取り込みは数回に分けて実行する必要あり（自動再開機能あり）
複数アカウント運用1スプシ = 1IGアカウント。複数アカウントを管理したい場合は、アカウントごとにスプシをコピー
ストーリーズOCRGemini API無料枠で月数百件は処理可能。商用ヘビー利用なら有料枠の従量課金が必要
トリガー時刻の精度±5〜15分のズレあり（GAS時間ベーストリガー仕様）

🔴 できない

項目理由
個人アカウントでの利用Instagram Graph APIは ビジネス/クリエイターアカウント のみ対応。個人アカウントは事前にビジネス/クリエイターに切替必須
ストーリーズのDM返信内容の取得API仕様で取得不可（プライバシー保護）
投稿の保存ユーザー一覧API仕様で取得不可（保存数の数値のみ取得可）
いいねしたユーザー名の一覧API仕様で取得不可（いいね数の数値のみ取得可）
フォロワーの個別属性API仕様で取得不可（性別・年齢層の集計値のみ・本テンプレートでは未対応）
過去ストーリーズの完全な数値復元Meta公式zipにも数値が含まれていない場合があるため、過去データの完全復元は構造的に不可能
他人のアカウントの非公開データ取得規約・法令違反のため絶対に行わない
HTMLスクレイピングによる代替取得Meta規約違反・不正アクセス禁止法のリスクのため絶対に行わない
自動投稿・自動コメント・自動DM本テンプレートは 読み取り専用。書き込み系は一切実装しない
📚 詳細な法的整理: 本テンプレートが「どこまで白で、何をやらないか」については setup-guide.html の Legal セクション も併せて確認してください。
⚠️ アカウントBANリスクへの備え: Instagram のアカウントが何らかの理由で凍結・削除された場合、Meta側の管理画面・API両方からデータが消えます。本テンプレートで定期的にスプシ・Driveに保存しておくことで、最低限のバックアップにはなりますが、BAN前に「Meta公式zip」と「API過去全件取り込み」の両方を一度実行しておくことを強く推奨します。
